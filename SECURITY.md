# Security and privacy

## Demo-data policy

This public mockup accepts only fictional sample data. Do not commit real procurement documents, reports, mailbox addresses, tenant URLs, connection exports, access tokens, or synchronized working folders.

## Local data

The `data/` directory, PDFs, generated Word files, logs, and environment files are excluded through `.gitignore`.

## Reporting issues

If you discover a security issue, open a minimal GitHub issue without including secrets or production data. For a real deployment, use the organization's private incident-reporting channel instead.
